Original abstract

Human demonstrations offer an efficient and scalable source of data for dexterous robot manipulation, but differences in sensing and hand morphology complicate the transfer of contact-rich interactions. We present TouchBridge, a hardware--software co-designed framework for human-to-robot data transformation. A wearable human demonstration interface and a corresponding robot interface establish cross-embodiment correspondence in visual and fingertip tactile sensing. We introduce Tac-Retarget, a tactile-conditioned retargeting method that uses measured contact to align fingertip contact patches and preserve their spatial relations within and across hands. Unlike object-aware or simulation-based transfer pipelines, Tac-Retarget requires no object mesh, object-pose estimate, or physics simulation for retargeting, enabling direct and scalable conversion of human demonstrations into robot-domain training data. Combined with visual synthesis and camera-anchored action conversion, TouchBridge produces robot-domain demonstrations for fine-tuning a pretrained vision-language-action (VLA) model. Across four real-world contact-rich tasks, policies fine-tuned solely on TouchBridge-converted human demonstrations achieve a 72.5% average success rate, compared with 77.5% using an equal number of teleoperated robot demonstrations, while human demonstration collection is 7.0x faster. Under the same policy and training setup, Tac-Retarget outperforms DexPilot and UniDex by 25.0 and 42.5 percentage points, respectively.

Legged Robot State Estimation With Dynamic Contact Event Information

Joon-Ha Kim, Seungwoo Hong, Gwanghyeon Ji, Seung-Hun Jeon, Jemin Hwangbo, Jun-Ho Oh, Hae-Won Park

Published 2021-06-30 Source IEEE Robotics and Automation LettersReading focus robot_state_estimation

Takeaway

This letter formulates legged-robot state estimation as a Maximum A Posteriori problem solved with Gauss-Newton, using Schur-complement marginalization to keep the problem fixed-size and deriving cost terms and Jacobians on the SO(3) manifold with a nominal-state plus variation reparameterization. It further proposes a slip rejection method to reduce errors from fault modeling of kinematics models. The algorithm is verified by comparison with the Invariant Extended Kalman Filter (IEKF) in real robot experiments across various environments, with the abstract reporting no numerical outcomes. The point to inspect is how slip rejection is triggered and how the MAP formulation and marginalization affect estimator behavior relative to the IEKF baseline.

Original abstract

This letter presents a state estimation algorithm for the legged robot by defining the problem as a Maximum A Posteriori (MAP) estimation problem and solving the problem with the Gauss-Newton algorithm. Moreover, marginalization by the Schur Complement method is adopted to make a fixed size problem. Each component of the cost function and its Jacobian are derived utilizing the SO(3) manifold structure, while we reparameterize the state with nominal state and variation to make linear algebra and vector calculus applied properly. Furthermore, a slip rejection method is proposed to reduce the erroneous effect of fault modeling of kinematics models. The proposed algorithm is verified by comparison with the Invariant Extended Kalman Filter (IEKF) in real robot experiments on various environments.
